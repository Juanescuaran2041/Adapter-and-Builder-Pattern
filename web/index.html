Bridge (crop - irrigation method)

Crop (PotatoCrop, QuinoaCrop, FavaBeanCrop) has an IrrigationStrategy (DripIrrigation, SprinklerIrrigation, FurrowIrrigation). Any crop can use any method without making 9 classes, and the method can be changed with the "Irrigation method" select.

Adapter (sensors)

The 3 sensors give the data in different ways (0-1023, a text frame and centibars). Each adapter converts it so the program only calls readSoilPercentage().
